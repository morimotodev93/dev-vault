# Dev Vault

A lightweight knowledge-management application for storing and organizing development snippets, notes, and reusable code examples.

## Overview

Dev Vault is built with Next.js, React, TypeScript, Prisma, and SQLite.

The project focuses on building a simple and extensible CRUD application for managing reusable development knowledge.

## Features

- Snippet CRUD
- Snippet search
- Pagination
- Favorite management
- Tags
- Responsive UI
- Form validation
- SQLite database
- Prisma ORM

## Tech Stack

- Next.js
- React
- TypeScript
- Prisma
- SQLite
- Zod
- CSS Modules
- pnpm
